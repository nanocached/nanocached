Deployment

These pages cover what the binaries need from any deployment, whatever runs them: the operations endpoint and the drain that makes scale-in lossless, TLS, metrics collection, and the proxy tier.

  • What every deployment needs — the operations endpoint (/healthz, /readyz, /metrics), the metrics to scale on, and the SIGTERM drain that makes scale-in lossless.
  • TLS — which segments each flag encrypts, why node certificates carry IP addresses, self-signed certificates and a private CA, how to distribute them, and leaf and CA rotation.
  • Metrics collection — what /metrics exports and how gauges and counters behave once collected.
  • The proxy tier — when a cluster needs nanocached-proxy, where it runs (with the cluster, in the cluster's own shape), how many, how applications reach it, and the sidecar alternative.
